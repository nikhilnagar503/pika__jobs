# Pikajobs admin manual

How to run the admin workspace. The same guide is in the app at `/admin/manual`.

Only `nagarn603@gmail.com` can open `/admin`.

## Overview numbers

| Number | Meaning | Where to open it |
| --- | --- | --- |
| Live on feed | Published jobs still inside the 14-day window. Students can see these. | Admin feed → Live |
| Drafts | Saved but not live. | Admin feed → Drafts, then Publish |
| Archived | Left the live feed. Deleted by you, or aged past 14 days. | Archive |
| Members | People who signed up, including the admin account. | Members |

## Post jobs

1. **Post a job** — type one listing, then Save draft or Save and publish.
2. **Import JSON** — upload a file, preview every row, then post. Email-only jobs are valid if an HR email is present.
3. On a draft card, click **Publish** to put it on the student feed.

## JSON import

After upload you see Ready vs Cannot post, with company, title, and reason. After posting you see Posted, Not posted, and Failed. Same company + title cannot be live twice in the 14-day window.

## Drafts vs live

Drafts stay off the student feed until you publish. Open Drafts, then Publish on the card or Publish all drafts. If publish fails, the reason stays on the card — often a duplicate of a live listing.

## Archive

Archive lists every job that left the live feed.

- **Deleted by admin** — you (or bulk delete) removed it.
- **visibility_cutoff** — the 14-day window ended.

Students do not see archived jobs.

## Members

Members is the sign-up list: name, email, date, and role. This count is accounts, not page views.

## Student feed rules

Students only see published jobs from the last 14 days. Newest upload/publish time is first. Apply happens on the employer site or by email.
